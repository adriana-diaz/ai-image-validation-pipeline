# AI Image Validation Pipeline

Conceptual project focused on validating and curating images before AI model training in industrial and automation contexts.

---

## 💡 Background
Inspired by real-world manufacturing use cases where robotics systems capture images (e.g., valve readings) that must be validated to ensure quality and consistency before training computer vision models.

The pipeline concept includes:
- Checking image integrity and resolution
- Filtering invalid or inconsistent samples
- Generating reports for dataset quality control
